Déposer ici le modèle Gemma au format MediaPipe, ex. `gemma3-1b-it-int4.task`
(téléchargeable sur Kaggle / Hugging Face « litert-community », licence Gemma à accepter).
Le fichier n'est pas précaché : il est mis en cache par le ServiceWorker au premier
appel de `preloadLocalModel()` (à déclencher pendant que l'utilisateur est en ligne).
